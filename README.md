A website that brings astronomy content from NASA into an interactive web experience.

**Live demo:** https://mahmoudmohamed99-ai.github.io/interactive_website/

## Features

- Fetches astronomy data from a NASA API.
- Displays information and images returned by the API.
- Updates the page dynamically with JavaScript.
- Uses a simple web interface to present the data.

## Built with

- HTML
- CSS
- JavaScript
- NASA API



## How it works

The website requests data from NASA's API and uses the response to update the page. This project was a way to practice working with external APIs and connecting JavaScript to real data.
